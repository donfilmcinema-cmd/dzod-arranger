DZOD Arranger — сборка песни из версий Suno

Установка: распакуйте папку куда удобно (например C:\Program Files\DZOD\Arranger или на рабочий стол)
и запустите «DZOD Arranger.exe». Установщика нет, права администратора не нужны.
Windows может спросить про неизвестного издателя — «Подробнее» → «Выполнить в любом случае».
Ярлык: правой кнопкой по exe → «Отправить» → «Рабочий стол (создать ярлык)».

Как работать:
1 Song & variants — LOAD FILES… (стемы версии, можно выбрать папку) или перетащите папки версий в окно.
  Роль стема берётся из имени файла (Drums, Bass, Guitar, Keys, Synth, Backing Vocals, Vocals…), клик — сменить.
  GO TO ARRANGING — анализ (темп, такты, тональность), все версии ложатся на стол друг за другом.
2 Arrange — курсор по линейке, S / SPLIT — разрез на сильной доле, Delete — удалить кусок, перетаскивание — порядок,
  правая кнопка по стему — убрать инструмент из куска / образец, PART — метка части (Intro, Verse, Chorus…),
  COMPARE — слушать куски на равной громкости, Space — Play/Stop, Ctrl+Z / Ctrl+Y — отмена/повтор.
3 Tempo — ANALYSE (темп кусков, предложение), поле BPM, ALIGN — растяжка к темпу и на такты.
4 Unify sound — образец, сила, предел для каждого инструмента, START UNIFY.
5 Mix into stems — Neuro Drums / Bass / Guitar / … (WAV 48 кГц 24 бит, с 1-го такта).
6 Save · Export — SAVE NEW STEMS по шаблону, EXPORT SONG (MP3 320 / WAV 24 / WAV 16).
Проект: SAVE / OPEN (файл .dzarr). Кэш анализа: %APPDATA%\DZOD\Arranger\cache.
